Put your print files here, named after the product slug in lib/products.ts:

  vortex-vase.stl      → product "vortex-vase" shows this model in 3D
  name-keychain.3mf    → product "name-keychain"

Supported: .stl  .3mf (Bambu Studio / Orca / PrusaSlicer projects)  .obj  .glb  .gltf
Then run:  npm run models   (also runs automatically on npm run build)

These source files are NOT published; only the small converted copies in public/models/ are.
